## My process

I started by creating the HTML structure for the QR code card and its content.

### What I learned

This project helped me improve my understanding of how HTML and CSS work together to create a simple but well-structured component.

I practiced using Flexbox to center the component on the page:

```css
body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

I also improved my understanding of spacing, border radius, image sizing, typography, and how small CSS changes can make a big difference when trying to accurately reproduce a design.
